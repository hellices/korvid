# korvid v0.7.1

v0.7.1 is a documentation update to v0.7.0. It changes no feature:
everything in the
[v0.7.0 release notes](https://hellices.github.io/korvid/release-notes/v0.7.0/)
still applies.

## Why upgrade

The README is korvid's project description on PyPI, and it ships inside every
wheel and source archive. v0.7.0's README compared korvid with other tools.
v0.7.1 describes korvid on its own.

The TUI, the agent, MCP and every dependency are the same as in v0.7.0, so
there is no functional reason to upgrade.

## Documentation

- The README and the documentation describe korvid without comparing it with
  other tools.
- The README now states in its own words that over MCP, every external read
  shows up on your screen, and opt-in write proposals wait for your approval
  there.

The safety perimeter is unchanged. Agent investigation remains read-only.
Agent writes remain structured tools with no shell. The resolved policy arms
only exact registry tool names, import-time metadata validates dispatch, and
`ToolExecutor` rejects an unknown tool. It performs typed argument validation
before every dispatch. Every write opens an approval dialog, requires a fresh
approval keystroke, and revalidates the exact target UID. Results still pass
through masking, and audit logging remains fail-closed.

## Kubernetes versions verified

Kubernetes 1.33, 1.34, 1.35 and 1.36, by the Kubernetes version matrix on
throwaway kind clusters.

## Install or upgrade

Install with `uv`:

```bash
uv tool install 'korvid[all]==0.7.1'
```

Reinstall the exact version with `uv` or `pipx` when upgrading:

```bash
uv tool install --force 'korvid[all]==0.7.1'
pipx install --force 'korvid[all]==0.7.1'
```

Homebrew users get v0.7.1 from `brew upgrade korvid` once the tap is updated.

## Verify

After the maintainer publishes the
[GitHub release](https://github.com/hellices/korvid/releases/tag/v0.7.1),
download its artifacts, verify both attestations, and check the wheel against
the checksum manifest:

```sh
set -eu
gh release download v0.7.1 --dir dist/v0.7.1 --repo hellices/korvid
gh attestation verify dist/v0.7.1/korvid-0.7.1-py3-none-any.whl --repo hellices/korvid
gh attestation verify dist/v0.7.1/SHA256SUMS --repo hellices/korvid
(cd dist/v0.7.1 && shasum --algorithm 256 --check SHA256SUMS)
uvx --from 'korvid[all]==0.7.1' korvid --version
```

The final command must report `korvid 0.7.1`.
