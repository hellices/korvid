# v0.5.0 Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:subagent-driven-development` or
> `superpowers:executing-plans` task by task.

**Goal:** Prepare the exact, reversible source revision for korvid `v0.5.0`
without tagging or publishing.

**Architecture:** Keep release metadata in `pyproject.toml`, derive runtime and
release contracts from it, turn the accumulated Unreleased page into one
concise versioned note, and keep product-state truth in a small internal
capability ledger. Existing release automation remains unchanged and is run
only from merged `main`.

**Tech Stack:** Python 3.11+, uv, pytest, MkDocs Material, GitHub Actions.

## Global constraints

- Work in `.worktrees/release-v0.5.0-prep` on
  `release/v0.5.0-prep`.
- Do not modify production behavior or dependencies.
- Do not tag, publish, create a GitHub Release, dispatch the Release workflow,
  or update the Homebrew tap from this branch.
- Do not open a pull request without explicit maintainer instruction.
- Do not modify the main checkout's dirty `uv.lock`.
- Re-lock only with all uv index configuration neutralized as documented in
  `docs/dev/quality-gates.md`.
- Use strict TDD for release contracts and documentation behavior.
- Keep `v0.5.0` notes concise and user-facing; link the milestone instead of
  narrating every issue.
