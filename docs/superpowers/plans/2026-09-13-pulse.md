# Ambient Pulse Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for
> independent work and keep tightly coupled integration local. Apply TDD.

**Goal:** Deliver #389 as a continuously visible, bounded read-only attention
summary with evidence-based detail and safe resource navigation.

**Architecture:** Share existing live Warning input; reconcile bounded fresh
snapshots separately. Pure extensible rules and a bounded recent-event model
feed a dedicated UI controller, wired only in `__main__.py`.

**Tech Stack:** Python 3.11+, Textual 8, kubernetes_asyncio, pytest, YAML fixtures.

## Global constraints

- Follow `2026-09-13-pulse-design.md`; no Agent/MCP/observability requirement.
- No cluster writes, new watch fan-out, public plugins, or merge automation.
- Two pages × 100 objects × 256 KiB per source; five-second source deadline.
- One in-flight request; 15-second refresh; 100 recent events / 128 KiB / 15 min.
- Current retention per rule source: 200 findings / 256 KiB; loss is not recovery.
- TDD, targeted checks while iterating; `make check` before commits and reviews.
- All edits use `apply_patch`; no new inline code comments.

## Task 1: Pure state and extensible rules

Files: `core/pulse.py`, `core/pulse_rules.py`, `tests/core/test_pulse.py`,
`tests/core/test_pulse_scenarios.py`, `tests/fixtures/pulse/*.yaml`.

Contract: immutable `PulseTarget(group, kind, namespace, name, uid)`,
`PulseItem(key, category, target, reason, message, observed_at, count, finding)`,
`PulseCoverage(source, state, observed_at, detail)`, `PulseSnapshot`.
`PulseRule` is an ABC exposing `source` and
`evaluate(objects, observed_at) -> tuple[PulseItem, ...]`.
`can_clear(resource) -> bool` is the generic assessment seam for incomplete status.
`PulseModel(rules=...)` exposes `reset(epoch, scope)`,
`replace_source(source, objects, coverage)`, `record_warning(event, epoch,
observed_at)`, and `snapshot(now)`; output records carry epoch/scope.

## Task 2: Bounded Kubernetes collection

Files: `k8s/pulse.py`, `core/pulse_collector.py`, `k8s/client.py`,
`tests/k8s/test_pulse.py`, `tests/k8s/test_pulse_transport.py`,
`tests/core/test_pulse_collector.py`.

`PulseSource(key, group, version, plural, field_selector="")` names an input.
`PulsePage(items, continuation)` is a decoded bounded page. `PulseReader`
defines `read_pulse_page(source, namespace, continuation, limit, max_bytes)`.
KubeClient implements it without extending the unrelated `ReadOps` fakes.
`PulseCollector(reader, sources)` returns each source's objects and coverage.
